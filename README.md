# PROYECTO-GESTION-MEDICO
Proyecto desarrollado en Python para la gestión de una clínica médica mediante consola.
Funcionalidades-
Registro y gestión de hospitales.
Registro de médicos y pacientes.
Asignación de médicos a pacientes.
Gestión y consulta de citas médicas.
Historial clínico de los pacientes.
Registro de diagnósticos e informes médicos.
Validación de DNI, correo electrónico, teléfono, género y fechas.
Control de errores mediante excepciones personalizadas.
Búsqueda de médicos y pacientes.
Menú interactivo para gestionar todas las operaciones.
